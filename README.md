# 架空のカフェのランディングページ。店名は灯珈琲

## 1.目的：このLPを見た人に、最終的に何をしてほしいか。
- 来店してほしい。理由は予約などのハードルを感じず、気軽にお店に来てほしいから。お店の雰囲気を事前に感じてもらい、いい印象をもってもらう。
- 個室の予約をページを通してしてもらう。

## 2.ターゲット：誰に向けたページか。
- 20代から50代ぐらいの仕事している大人がターゲット。コーヒーに詳しくないライト層がターゲットで、コワーキングスペースとしての役割も兼ねているので、フリーランスやリモートワークで仕事している方に向けたページ。

## 3.伝えること：
- お店の電話番号
- 住所
- 営業時間
- googleマップの案内
- 商品や店内の写真
- 商品の料金表（コーヒーや軽食などの料金）
- 焙煎機の写真、焙煎したて、挽きたてのコーヒーであることをアピールする。
- 席の料金表(1時間ごとに、440円、ドリンク代は含まない)
- 個室の利用時間＋料金、予約方法、予約ページ（個室料金１時間あたり880円）
- 作業に必要な環境面（無料Wi-Fi、通信速度、USB、コンセント）
- 図書館のように自由に読める本や漫画がある。

## 4.セクション構成
- ヘッダー　店名　各セクションに飛べる項目
- メイン　商品や店内の写真、焙煎機の写真、説明文（ここで作りながら決める）
- 環境　作業に必要な環境面、図書館のように自由に読める本や漫画がある。
- インフォ　googleマップの案内、住所、お店の電話番号、営業時間
- 料金　商品の料金表　席の料金表、個室の利用時間＋料金、予約方法、予約ページ
- フッター　、お問い合わせ、お店のロゴ、SNSのアイコン

- 暖色系　クリーム色　秋っぽい　上品なフォント
