# 要件定義書

## コーヒー豆のランダムおすすめ機能

### 機能概要

ボタンを押すと、複数のコーヒー豆パックが横方向にスライドしてシャッフルされ、ランダムに選ばれた豆が表示される。

## 想定する機能の流れ

1. コーヒー豆の候補となる写真を複数枚用意する（AI生成画像でも可）。
2. 写真を横に並べて表示し、その下にシャッフルボタンを配置する。
3. ボタンを押すと、右から左へのスライドアニメーションを約5秒間再生し、ゆっくり停止させる。
4. アニメーションの停止後に効果音（SE）を再生し、選ばれた豆を大きく表示する。

スライドアニメーションと効果音の実装は難しそうなため、1週間の締め切りに間に合うよう、まずは最低限動作するMVPの作成を優先する。

## MVP

ボタンを押すと、コーヒー豆の写真がランダムに1枚表示される機能を作成する。

### 必要なコードの整理

- [x] コーヒー豆の名前と写真を対応づけた配列を作成する。
- [x] ボタンが押されたとき、ランダムに生成した数字に基づいて値を返す。
- [x] 戻り値に対応する写真をDOM操作で表示する。

### 今後の課題

現状では、ボタンを押しても前回と同じ数字が選ばれる可能性がある。その場合、ボタンを押しても画像が変わらないため、同じ数字が連続したときの処理を条件分岐などで実装する必要がある。

あとスライドアニメーションどうやってつくればいいのかはさっぱり

## STEP 3

- [x] 「今日の豆は〇〇です」と表示する演出を追加する。
  - いつ　シャッフルが完了したとき
  - どこに　左側が空いてるのでそこに
  - 何を　今日の豆は〇〇です。と〇〇に決まった豆の名前を表示し、余裕があればその産地の説明やコーヒーの味わいの特徴を説明する文章を作成する

  - [] 途中で出たアイデア。豆の名前を表示するだけでなく、画像の左側に枠を作り、そこに豆の産地の詳細とか味わいの５段階評価を表示するようなものがあったほうがいいと感じた。コーヒーに詳しくなくても、どんな味わいなのかがぱっと分かるような。５段階評価がいいかな。苦み・酸味・甘み・コク・香りの５項目

- [ ] 結果が出たときに画像を大きく表示し、選ばれたことが伝わる演出を追加する。
