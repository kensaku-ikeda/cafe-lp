# 要件定義書

## コーヒーのlpに組み込むランダムでおすすめの豆が選出される機能

**詳細な機能面について**

- ボタンを押すと、いくつかのコーヒー豆パックが横にスライドアニメーションーでシャッフルされ、ランダムに一つ決まって表示される。


## どのようなコードが必要になるか
機能の流れとしては、
1. まずコーヒー豆の候補の写真を小さいサイズでいくつか用意する。AI画像でもいいとおもう。

2. その写真を横に並べるように表示し、下側にはおしゃれなシャッフルボタンを配置する。

3. ボタンをおすと右から左にスライドアニメーションが５秒ほど再生され、ゆっくり止まる。

4. とまると、SEが流れたのち、選出された豆が大きく表示される。

- 3のスライドアニメーションと４の効果音については実装が難しそうなので、
１週間の締め切りを間に合わせるには、最低限動くMVPの作成を優先させる。

## MVP
- ボタンを押すと、豆の写真がランダムに一つ表示される。まずはこれを作成する。

### 必要になるコードを日本語で言語化
1. コーヒー豆の写真ごとの名前が用意された配列をつくる。

2. イベントでボタンが押されたときにランダムに生成された数字に基づいて変数を戻り値で返す。

3. 帰ってきた戻り値に対応した写真をDOM操作で表示させる。
